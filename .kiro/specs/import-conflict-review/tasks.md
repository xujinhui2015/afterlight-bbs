# 实现任务

以下任务由 Codex 预先整理，全部等待在 Kiro 中实际执行与核验。完成后再勾选，并在 `docs/kiro-worklog.md` 填入真实记录。

- [ ] 阅读现有领域逻辑、界面和测试，审查需求及设计。
- [ ] 实现导入分析与显式冲突决策的纯函数。
- [ ] 验证文件内部重复 ID、字段顺序、取消与幂等性边界。
- [ ] 实现带本地版/导入版选择的预览对话框。
- [ ] 确认提交前检测本地数据变化，避免覆盖预览后的新修改。
- [ ] 验证键盘操作、焦点恢复、窄屏与安全文本渲染。
- [ ] 运行 `npm test`、`npm run build`，在生产预览验证离线导入。
- [ ] 更新说明、演示步骤和 Kiro 实际工作记录。
