# 产品与开发约束

Afterlight BBS（余烬公告板）将早期 BBS 复活为可离线使用的社区求助与资源整理工具，参赛目标是 Kiroween 2026 Resurrection。

- 交流、界面和代码注释使用中文；变量、函数和文件名使用英文。
- 保持 Vite 与原生 JavaScript，初版不需要在线 API、账户或后端。
- 保留离线功能、相对资源路径和 GitHub Pages 子路径兼容性。
- 将校验、搜索、匹配与导入合并放在独立纯函数中。
- 用户输入以文本方式渲染，不用 `innerHTML` 插入公告内容。
- 对导入文件校验结构、字段、长度和允许值；失败时不修改现有数据。
- 修改导入策略前先展示影响，取消操作不得改变数据。
- 不把原型宣传为实时救援服务或跨设备实时同步系统。
- 不声称规则匹配使用在线 AI。
- 不提交凭据、私密数据或真实联系人；公开示例为虚构内容。
- 不删除或忽略 `.kiro/`；只记录真正执行过的 Kiro 工作与验证结果。

完成改动后运行 `npm test` 和 `npm run build`，并在 `docs/kiro-worklog.md` 记录实际结果。
