## 建议实际执行的任务

用 Kiro 打开仓库，读取 `.kiro/steering/product.md` 和 `.kiro/specs/import-conflict-review/`，要求 Kiro按需求、设计、实现和验证流程完成 **JSON 导入冲突预览与选择**：

1. 审查规格，指出边界条件并确认设计。
2. 为导入数据建立纯函数分析结果，区分新增、重复与冲突。
3. 实现预览界面，让用户逐条保留本地版本或采用导入版本。
4. 验证取消不改数据、重复导入不增加条数、解决冲突不影响无关公告。
5. 更新规格任务状态、提交相关代码，并填写下方记录。

这些步骤是待办，不是完成声明。无需为参赛虚构未实际使用的 Kiro 功能。
